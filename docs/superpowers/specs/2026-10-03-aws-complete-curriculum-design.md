# Programa completo AWS CLF-C02

El programa conserva Firestore como origen del contenido, la navegación actual y el progreso por lección. El catálogo tendrá una lección por cada uno de los 19 enunciados de tareas de la guía oficial CLF-C02, agrupadas en cuatro dominios con ponderaciones 24/30/34/12. Cada lección incluirá lectura breve, ejemplos de elección de servicios y al menos dos preguntas explicadas. Los identificadores de las cuatro lecciones existentes se conservan para no perder el avance guardado.

La práctica admitirá preguntas de una respuesta y de varias respuestas. En ambos casos el alumno seleccionará y confirmará antes de ver la explicación; no podrá cambiar una respuesta confirmada. El porcentaje se calcula por preguntas completamente correctas. La interfaz mostrará el siguiente tema desde el resultado y presentará el curso como un temario completo, sin prometer equivalencia con el examen oficial.

La validación del catálogo seguirá aceptando el documento publicado anterior durante el despliegue. La prueba del archivo fuente comprobará todos los códigos de objetivo, ponderaciones, unicidad y volumen mínimo de práctica. El publicador seguirá exigiendo el proyecto de Firebase explícito.

Fuente: [guía oficial CLF-C02](https://docs.aws.amazon.com/es_es/aws-certification/latest/cloud-practitioner-02/cloud-practitioner-02.html).
